# Haven — Rental Management

A lightweight rental management app for landlords to manage properties, tenants,
leases, rent payments, and maintenance requests.

## Run locally

Open `index.html` in a modern browser. The app works without a build step or
external dependencies. Portfolio data is stored in the browser's local storage.

The starter portfolio is sample data. Use the navigation to review the dashboard,
properties, tenancies, rent tracking, and maintenance tickets. Add properties and
tenancies, record payments, mark rent as paid, and update ticket statuses from
the maintenance list.
